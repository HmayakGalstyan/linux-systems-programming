# Linux Systems Programming in C

Educational projects exploring Linux process management,
signals, and system calls using C.

## Processes
- process1.c - Process groups and coordination
- process2.c - Program execution using execv()
- process3.c - Child termination and exit status
- process4.c - Watchdog and alarm signals
- process5.c - Parent-child signal communication

## Signals
- signal1.c - Signal handling examples
- signal2.c - Binary output using signals
- signal3.c - Signal blocking and pending signals
- signal4.c - Signal-driven state management

## Technologies
C, Linux, GCC, POSIX APIs

## Status
Educational exercises. Some programs require further
testing and improvements.
